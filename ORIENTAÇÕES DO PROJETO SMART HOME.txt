<!--PLANEJAMENTO DE REQUISITOS (Antes de programar, explique exatamente o que seu sistema vai fazer e para quem.)-->


• Definição do Problema

	Atualmente, sistemas de automação residencial executam comandos configurados previamente pelo usuário, mas não necessariamente analisam seus hábitos para sugerir ações automaticamente. O projeto propõe uma plataforma capaz de registrar informações sobre consumo de energia, temperatura, horários de utilização dos dispositivos e preferências dos moradores, utilizando esses dados para identificar padrões e realizar previsões.


	--------------------||--------------------

<!--PÚBLICO ALVO (Quem vai utilizar o sistema?)-->


Morador
Pode:

• visualizar consumo;
• visualizar temperatura;
• cadastrar dispositivos;
• visualizar recomendações;
• consultar o chatbot;
• visualizar previsões;
• configurar preferências.

Administrador
Pode:

• cadastrar/editar/remover dispositivos;
• visualizar moradores;
• visualizar dados gerais;
• consultar histórico;
• visualizar métricas;
• administrar o sistema.
